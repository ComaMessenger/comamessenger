# Фаза 3.1. Навигация и настройки

Статус: завершена 21 августа 2026 года.

## Результат

Фаза закрывает полноценную информационную архитектуру настроек до файлов и глобального поиска. На desktop и phone настройки открываются в основной рабочей области, а не в dialog. Все production controls работают через зафиксированный OpenAPI; декоративных выключенных настроек нет.

Реализованы полноэкранные routes:

- `/settings/profile` — имя, handle, тема и язык;
- `/settings/notifications` — browser push, состояние разрешения и privacy preview;
- `/settings/security` — активные сессии, отзыв отдельной сессии и logout со всех остальных устройств;
- `/settings/workspace` — название, slug, приглашения, политики создания чатов, роли и деактивация участников;
- `/settings/customization` — логотип, favicon и runtime accent color;
- `/settings/infrastructure` — masked S3-compatible и SMTP configuration с серверной проверкой подключения;
- `/settings/audit` — последние административные события.

На phone глобальная навигация остаётся нижним tabbar `Чаты / Треды / Важные / Участники / Ещё`. Внутри settings используется горизонтальная прокручиваемая навигация, учитывающая safe area и длину локализованных строк.

Все изменяемые поля сохраняются автоматически с debounce. Клиент сериализует запросы, не затирает новые правки устаревшим ответом, показывает состояния «Сохраняем / Сохранено / Ошибка» и предлагает явный retry. Кнопки сохранения в settings отсутствуют; отдельными действиями остаются только приглашения, загрузка assets, проверка соединений и отзыв сессий.

## Серверные контракты

- Organization settings имеют `version` и обновляются через optimistic concurrency (`expected_version`).
- Политика приглашений задаёт реальную default role и TTL; созданная одноразовая ссылка возвращается администратору для безопасной передачи участнику.
- `allow_public_chat_creation` и `allow_channel_creation` проверяются сервером для обычного участника.
- Owner управляет ролями; owner/admin могут деактивировать допустимых участников. Constraint базы не позволяет удалить последнего активного owner.
- Public branding доступен до авторизации. Логотип и favicon — ограниченные 512 KiB binary resources в PostgreSQL; SVG запрещён, MIME сверяется с содержимым, ответы отдаются с `nosniff`.
- Accent color применяется к CSS semantic tokens, title и favicon обновляются без перезагрузки.
- S3 поддерживает AWS S3, Selectel, Yandex Object Storage, MinIO и другие S3-compatible endpoints через region, endpoint и path-style mode.
- SMTP поддерживает `STARTTLS`, implicit `TLS` и явно выбранное соединение без TLS.
- S3/SMTP credentials шифруются AES-GCM с `INTEGRATION_ENCRYPTION_KEY`, привязаны к organization ID и никогда не возвращаются клиенту. UI получает только флаг и masked access-key hint.
- Connection test выполняется сервером с timeout; браузер не получает secret и не подключается к инфраструктуре напрямую.
- Каждая административная мутация пишет audit event.

S3 configuration в этой фазе сохраняется и валидируется. Подключение её к attachment pipeline является входом фазы 4: до появления file contract UI не показывает несуществующую загрузку файлов.

## Проверки

- Go unit tests покрывают шифрование, organization-bound AAD, masking, provider-neutral validation и member authz.
- HTTP integration scenario покрывает organization update/version, member 403, public branding, binary asset, encrypted infrastructure, connection test, members и audit.
- TypeScript boundary check гарантирует отсутствие React imports в `packages/core`.
- Vitest проходит для engine и Web primitives.
- Playwright проходит на desktop и phone для всех settings routes, autosave, прокрутки, уведомлений, приглашения, branding upload, S3/SMTP save/test, sessions и audit.
- RU/EN и pseudo-locale каталоги синхронизированы; формы используют labels над полями, logical sizing и responsive grids.

## Definition of Done

- [x] Settings не открываются в dialog на desktop или phone.
- [x] Profile changes отражаются без перезагрузки.
- [x] Все поддерживаемые настройки сохраняются автоматически и не требуют кнопки Save.
- [x] Длинные страницы настроек прокручиваются на desktop и phone.
- [x] Member не может вызвать административные workspace mutations.
- [x] Secrets не возвращаются и не попадают в browser storage.
- [x] Branding применяется до login и обновляется live.
- [x] S3/SMTP configuration можно сохранить и проверить.
- [x] Роли, деактивация, приглашения, sessions и audit имеют рабочий UI.
- [x] OpenAPI, generated TypeScript/Go types, tests и deployment обновлены вместе.

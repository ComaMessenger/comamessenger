# Документация ComaMessenger

Документация разделена на три уровня:

- [`product-spec.md`](product-spec.md) — исходное продуктовое и архитектурное ТЗ;
- [`decisions/`](decisions/) — принятые решения, которые влияют на весь продукт;
- [`phases/`](phases/) — отдельный scope, задачи и критерии готовности каждой фазы.

## Терминология

- **Чат** — пространство, где все участники могут писать сообщения.
- **Канал** — пространство для публикаций: писать могут владелец и администраторы, остальные участники читают и реагируют.
- **Личный чат (DM)** — переписка двух участников.
- **Тред** — отдельная ветка обсуждения сообщения внутри чата или канала.

На уровне протокола и базы данных используется общая сущность `chat`. Режим задаётся полем `kind`: `group`, `channel` или `direct`. Это позволяет использовать единые сообщения, треды, права, поиск и события, сохраняя разное поведение чатов и каналов.

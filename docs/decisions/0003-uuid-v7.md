# ADR-0003: UUIDv7 для идентификаторов

- Статус: принято
- Дата: 2026-08-18

## Контекст

Идентификаторы нужны во всех клиентах и в Postgres. Они должны иметь стандартное представление, эффективно храниться и не определять порядок доставки сообщений.

## Решение

- Primary/foreign keys доменных сущностей используют UUIDv7 и тип Postgres `uuid`.
- UUIDv7 генерирует Go-сервер; генерация в Postgres не является обязательной для поддерживаемой версии Postgres 16.
- Клиент создаёт отдельный UUID `client_msg_id` для идемпотентности и связи optimistic message с серверным результатом.
- Порядок сообщений, unread и realtime resume определяется серверными sequence numbers, а не UUID.

## Последствия

- ULID не используется в новых контрактах и миграциях.
- Временная составляющая UUIDv7 не считается секретом.
- Авторизация никогда не основывается на непредсказуемости ID.
- При обновлении до Postgres 18 можно использовать встроенный `uuidv7()`, не меняя тип колонок.

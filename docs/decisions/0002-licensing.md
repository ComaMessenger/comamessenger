# ADR-0002: лицензирование

- Статус: принято
- Дата: 2026-08-18

## Контекст

Сервер должен оставаться открытым даже при использовании изменённой версии как сетевого сервиса. Одновременно публичные клиенты, протокол и SDK должны быть удобны для корпоративных интеграций и сторонних приложений.

## Решение

- `core/` и `apps/agent-runtime/` распространяются под `AGPL-3.0-only`.
- Все остальные оригинальные файлы репозитория, включая клиенты, `packages/`, примеры, deployment assets, документацию и корневую build-конфигурацию, распространяются под `Apache-2.0`.
- Карта лицензий хранится в корневом `LICENSE`, канонические тексты — в `LICENSES/`.
- Новый файл наследует лицензию своего каталога, если в нём явно не указан другой SPDX identifier.

## Последствия

- Изменённая серверная часть, доступная пользователям по сети, сохраняет требования AGPL.
- Сторонние клиенты и интеграции могут использовать протокол и SDK без copyleft-обязательств AGPL.
- При перемещении кода через лицензионную границу требуется отдельная проверка совместимости.
- До принятия внешних contributions нужно зафиксировать DCO/CLA policy; по умолчанию предпочтителен простой DCO без передачи copyright.

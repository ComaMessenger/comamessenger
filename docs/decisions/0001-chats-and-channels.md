# ADR-0001: чаты и каналы

- Статус: принято
- Дата: 2026-08-18

## Контекст

Слово «канал» не должно обозначать любое пространство общения. Пользователь создаёт чат для совместного общения или канал для односторонних публикаций.

## Решение

Использовать общую техническую сущность `chat` с тремя режимами:

| `kind` | Название в UI | Кто может писать |
|---|---|---|
| `direct` | Личный чат | Оба участника |
| `group` | Чат | Все участники |
| `channel` | Канал | Владелец и администраторы |

Видимость группового чата или канала задаётся отдельно: `private` либо `public`.

Для канала участник без права публикации может читать и ставить реакции, но не может создавать сообщения ни в основной ленте, ни в тредах. Право писать определяется сервером, а не только интерфейсом клиента. Отдельный режим комментариев к публикациям, если он понадобится, будет оформлен самостоятельным решением.

## Последствия

- В API используется `/chats`, а тип пространства передаётся в `kind`.
- В базе используются таблицы `chats`, `chat_members` и `chat_reads`.
- События имеют префикс `chat.*` и поле `chat_id`.
- Создание канала — это `POST /chats` с `kind: "channel"`.
- Проверка отправки сообщений в основную ленту и треды выполняется централизованно в модуле авторизации.

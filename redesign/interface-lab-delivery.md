## Реализация

- Общие TypeScript/CSS-токены для Web, iOS и Android: нейтральные темы, отдельный цвет основных действий, семантический акцент Coma, пастельные аватары, шкалы отступов и радиусов.
- Web: базовые компоненты и рабочий каталог `/dev/components`; оболочка, навигация и чаты; сообщения, вложения, реакции, композер и треды; авторизация, диалоги, каталоги, настройки, управление агентами.
- Нативные iOS/Android: общие компоненты, авторизация/выбор сервера, табы и списки, переписка, вложения, треды, агентские сообщения и настройки. Сохранены safe areas, работа с клавиатурой, Dynamic Type и реальные сценарии API/offline. Основные touch targets не меньше 44 px.
- Исправлены найденные при интеграции скрытый экран обязательной смены пароля на телефоне, смещение мобильных заголовков настроек, узкие пресеты уведомлений, ширина заголовка треда на планшете и перенос подсказки агента на 320 px.
- Добавлены регрессионные проверки заголовков настроек/агентов и размеров 320/1024 px. Тестовые сессии теперь имеют относительный срок действия, а не уже истёкшую фиксированную дату.

- Новые и обновлённые визуальные снимки осмотрены. Веб-приёмка включает светлую/тёмную темы, desktop/phone, меню, треды, настройки и узкие экраны. История на 10 000 сообщений остаётся виртуализованной; повтор отправки сохраняет идентификатор команды.
- Prettier для изменённых исходников и `git diff --check` — успешно.
- Нативные TypeScript и 8 unit tests проверены независимо; production JS/Hermes exports iOS/Android собраны и проверены на наличие новых компонентов, токенов и всех assets.

## Нативная проверка

### Android — базовые сценарии проверены

- ARM64 debug APK успешно собран из текущего проекта за 27,9 секунды после прогрева кэша. Нативная сборка и установка завершились успешно; исходники, конфигурация и зависимости проекта не менялись.
- Pixel 8, Android 17 / API 37. Текущий Hermes JS действительно загружен из Metro с HTTP 200; это проверка обновлённого приложения, а не старого APK или Expo Go.
- На синтетическом локальном API проверены: выбор сервера, вход, светлая/тёмная темы, открытая клавиатура, список чатов, read-only канал, контекстное меню сообщения, каталог тредов и сам тред, переходы к профилю и уведомлениям.
- В чате с правом записи проверена отправка одного сообщения: запрос успешно принят mock API, сообщение появилось в ленте, композер очистился. Ввод и отправка остаются над экранной клавиатурой.
- Шрифт 2× проверен только на списке чатов. Профиль и настройки уведомлений осмотрены, но их сохранение в этой проверке не тестировалось.
- Сохранены 18 принятых снимков. Примеры: [отправленное сообщение](../design/review/interface-lab/android/message-sent-light.png), [композер с клавиатурой](../design/review/interface-lab/android/conversation-light-keyboard.png), [настройки в тёмной теме](../design/review/interface-lab/android/preferences-dark.png). Плавающая шестерёнка на снимках относится к dev-клиенту Expo.
- [ARM64 debug APK](../apps/mobile/android/app/build/outputs/apk/debug/app-debug.apk), 100 704 490 байт. SHA-256: `06f660ddea263a32e5e33bd42bf89f5890b889ec6d796f876876a7ccfccc8e9c`. Это dev-сборка для проверки с Metro, не release-артефакт.
- Тестовые данные приложения очищены; Metro, mock API и эмулятор остановлены. Все 113 контрольных хешей исходников/конфигурации и git status остались прежними.

Пределы проверки: один эмулятор, синтетический backend и базовые сценарии. На нативном runtime ещё не проверены вложения, редактирование/удаление, мутации реакций, streaming агентов, восстановление сети/outbox, многострочный рост композера, поиск, сессии, reset/invite и полная матрица доступности. Совместимость с реальным backend этой проверкой не подтверждается.

### iOS — проверка интерфейса остаётся открытой

TypeScript и JS/Hermes-экспорт успешно проверены. Существующие и новый временный симуляторы не смогли запустить даже Apple Settings; свежий iPhone 16 / iOS 18.2 завис при загрузке системного приложения. Это ограничение CoreSimulator на хосте. Текущий JS приложения в симуляторе не запускался. Временный симулятор удалён; существующие устройства не сбрасывались. Для визуальной приёмки нужен исправный iOS runtime или устройство.

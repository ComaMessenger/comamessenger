# Redesign — чего не хватает для полного соответствия макетам

Источник дизайна: проект Claude Design (канвасы «Авторизация», «Мессенджер», «Диалоги», «Агенты»), локальная копия — `design/claude-design/`. Раздел «Агенты» в этой итерации не трогали.

Здесь собраны разрывы между макетами и текущим API/продуктом, найденные во время реализации. Всё, что можно было сделать на существующем API, сделано; пункты ниже — задачи на бэкенд/продукт.

| Треды, Важные, Участники, мобильный раздел «Ещё» | [directories.md](directories.md) |

## Самое важное (кросс-модульное)

1. **`member_count` в `Chat`/`DirectoryChat`** — нужен в поиске, пересылке, шапке беседы, «Участники · N».
2. **`actor_display_name` в `SearchResult`, `Reaction`, `MessageReceipt`, событии `message.created`** — иначе имена приходится искать по списку участников текущего чата.
3. **Эндпоинт вложений чата** `GET /chats/{id}/files` (медиа/документы, размер, превью) и индекс ссылок `GET /chats/{id}/links` — вкладки «Медиа / Файлы / Ссылки» в инфо чата.
4. **Расширенные пины** `GET /chats/{id}/pins` с превью и автором, плюс `GET /me/pins` для раздела «Важные» (сейчас N+M запросов).
5. **Preview приглашения** `GET /invitations/{token}` (кто приглашает, куда, роль, срок) для экрана «Присоединиться».
6. **Тред**: `followed`, `thread_participants`, `thread_last_reply_at` в `Message`/`ThreadSummary`.
7. **Presence для всех `direct_peer`** из списка чатов и для каталога участников.
8. **Отложенная отправка** (`scheduled_at`) — пункт «Отправить позже…» отключён.

## Структура кода после рефакторинга

`apps/web/src/App.tsx` (6 400 строк) разобран на модули:

- `auth/` — экраны вне оболочки;
- `shell/` — оболочка, контекст мессенджера, realtime-сессия, глобальная панель, меню, таббар, Welcome;
- `chats/` — колонка списка чатов, строка, контекстное меню;
- `conversation/` — беседа, лента, строка сообщения, тред;
- `composer/` — композер и вложения;
- `dialogs/` — все диалоги и оверлеи;
- `directories/` — Треды / Важные / Участники / «Ещё»;
- `lib/` — форматирование, черновики, упоминания, папки, таймзоны;
- `styles/` — CSS по модулям (`settings.css` и `agents.css` вынесены без изменений);
- `i18n/` — базовые каталоги `ru.ts`/`en.ts`; новые ключи каждого модуля лежат в `<module>/i18n.ts` через `defineCatalog` (дубликаты падают в dev).

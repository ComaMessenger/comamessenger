# Справочники (Треды, Важные, Участники) и мобильный раздел «Ещё»

Что нужно от API/продукта, чтобы экраны выглядели как в макетах. Сейчас реализовано максимально близко на имеющихся данных.

## Треды

- **Автор корневого сообщения в списке.** `ThreadSummary.root` содержит только `actor_id`; имени/аватара автора нет, участники чата не подгружаются для каждого треда. Мета строки сейчас «Чат · время» вместо «Чат · Автор · время». Нужно: `actor_display_name` (и `avatar_version`) в `ThreadSummary` или в `Message`.
- **Название чата берётся из локального списка чатов.** Если чат ещё не загружен (например, тред в чате, из которого пользователь вышел), показываются инициалы по `chat_id`. Нужно: `chat_display_name`/`chat_avatar_seed` в `ThreadSummary`.
- **Пагинация** `threads(beforeSeq)` есть в API, в списке пока не используется (загружается первая страница). Кнопка «Показать ещё» добавится, когда появится реальный объём.
- **Время «последний ответ в 12:40»**: есть только `last_reply_seq`, без timestamp. Нужно `last_reply_at`.

## Важные

- **Кто закрепил.** `MessagePin.pinned_by` — только id, имя не резолвится без запроса участников каждого чата. Мета сейчас «Чат · время сообщения» вместо «Чат · закрепил Лев Кузнецов». Нужно: `pinned_by_display_name` в `MessagePin` или общий эндпоинт `/actors?ids=`.
- **Стоимость запроса.** Список собирается как `pins()` по каждому чату + `messageContext()` по каждому пину — N+M запросов. Нужен единый эндпоинт `/me/pins` (все закреплённые с текстом и автором).

## Участники

- **Presence для всех участников.** Точки статуса берутся из realtime-карты `store.presence`, которая наполняется только событиями по подписанным чатам; для остальных участники показываются как offline. Нужно: `presence` в `ActorSummary` или эндпоинт снимка присутствия.
- **Счётчик «14 человек и 2 агента»** считается по загруженной странице `actors()`; при пагинации число неполное. Нужны итоговые счётчики в `ActorPage`.
- **Открытие личного чата с участником** делается через `createChat(kind: direct)` — сервер должен возвращать существующий чат, если он уже есть (клиент сначала ищет локально по `direct_peer.actor_id`).
- **Статус «🏝 В отпуске до 15 сентября»**: срок (`status_expires_at`) есть, но в пилюле показывается только текст статуса — формат «до …» можно добавить, когда решим, показывать ли дату истечения.

## «Ещё» (mobile)

- **Подпись пространства «severny.coma.app · владелец»** — slug пространства не отдаётся в `User`, используется `window.location.host`. Нужно: `organization_slug` в `User` или публичный `host`/`slug` в branding.
- **Push-статус** берётся из `preferences.push_enabled` (общая настройка), а не из состояния текущего устройства/подписки. Нужно: признак «подписка есть на этом устройстве».
- **Bottom sheet «Статус»** — используется общий `StatusDialog` из модуля диалогов (в режиме sheet на мобильных).

# Новый пароль

Маршрут `/reset-password?token=…`, вне основной оболочки.

Auth-card: logo, заголовок «Новый пароль», lead, поля «Новый пароль» и «Повторите новый пароль», primary «Сменить пароль». Оба поля password, минимум 10 символов. Несовпадение показывает inline error до запроса. Отсутствующий/просроченный token — явное сообщение и disabled submit.

Pending: «Сохраняем…». Успех полностью заменяет форму на success-сообщение и primary «Вернуться ко входу». Ошибка сервера сохраняет введённые значения настолько, насколько это безопасно, и не уводит пользователя со страницы.

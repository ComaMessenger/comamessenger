# Первичная настройка пространства

Показывается один раз, когда сервер ещё не инициализирован.

Центрированная расширенная auth-card. Заголовок «Создайте пространство», пояснение. Форма desktop в две колонки, mobile — одна. Поля: bootstrap token (опциональный secret, на всю ширину), название организации, slug, имя владельца, handle, email, пароль минимум 10 символов. Primary «Создать пространство» на всю ширину.

Slug и handle визуально объясняются как технические идентификаторы; slug допускает lowercase latin/digits/hyphen и нормализуется в lowercase. Показать examples/hints, validation и error рядом с соответствующим полем либо общим form error. Pending блокирует повторный submit, но не очищает форму. Успех сразу аутентифицирует владельца и ведёт в чаты.

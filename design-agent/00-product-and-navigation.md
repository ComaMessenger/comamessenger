# Продукт и навигационная модель

## Что это за продукт

Coma — self-hosted рабочий мессенджер с личными чатами, группами, каналами, тредами, файлами, реакциями и встроенной платформой AI-агентов. Интерфейс спокойный, рабочий и информационно плотный; это не маркетинговое приложение и не социальная лента.

## Роли и доступ

- `member` общается и управляет личными настройками; в канале может быть только читателем.
- `admin` получает разрешения отдельными capabilities: участники, приглашения, политики, оформление, интеграции, агенты, аудит, модерация.
- `owner` имеет все разрешения и может передать владение.
- Элементы без разрешения обычно скрываются; прямой переход показывает нейтральное состояние «доступ только администратору».

## Карта навигации

Desktop: постоянная глобальная панель → при чат-маршруте отдельная колонка списка чатов → рабочая область. Utility-разделы, настройки и агенты занимают рабочую область без колонки чатов.

Mobile: фиксированная нижняя навигация из пяти иконок: Чаты, Треды, Важные, Участники, Ещё. В каждый момент показан один основной экран. Чат выезжает поверх списка, тред становится полноэкранным. Safe areas обязательны.

## Основные переходы

- `/chats` → фильтрованный список; `/chat/:id` → беседа; `/chat/:id/thread/:rootId` → тред.
- `/threads`, `/important`, `/members`, `/more` → utility-экраны.
- `/agents…` → глобальная платформа и карточка выбранного агента.
- `/settings…` → личные и workspace-настройки с permission-aware навигацией.
- Поиск, создание чата, папки, статус и уведомления открываются поверх текущего контекста.

## Универсальные состояния

Для каждого экрана предусмотреть: skeleton loading; содержимое; пустое состояние; локальную ошибку рядом с проблемной областью; disabled/pending для мутаций; успешное подтверждение; отсутствие доступа. При потере realtime показывается компактный индикатор offline, но сохранённые действия/сообщения не должны визуально исчезать.

## Требование к результату дизайн-агента

Нужны компоненты, variants, variables и auto-layout, а не набор несвязанных картинок. Имена слоёв и вариантов должны соответствовать продуктовой семантике: `ChatRow/Unread`, `Message/Grouped`, `Composer/Readonly`, `SettingsRow/Switch`, `Agent/NeedsAttention` и т. п.

# Настройки: профиль

Маршрут `/settings/profile`, доступен всем.

Общая SettingsShell: header с mobile Back в `/more`, primary tabs личных/workspace разделов по правам, центрированная колонка до ~680 px. Профиль начинается с avatar card: крупный avatar, Change avatar, Remove при наличии, hint по типу/размеру и inline validation.

Секция Personal preferences: Name, Handle, Job title, Timezone select/input, About textarea. Отдельная Appearance: Theme system/light/dark и Language RU/EN. Account actions: Logout.

Настройки автосохраняются с заметным Saving/Saved/Error состоянием; avatar upload — отдельный pending. Custom status здесь намеренно не редактируется: он находится в profile menu/More. На mobile avatar actions выравниваются слева, поля в одну колонку.

# Согласования действий агентов

Маршрут `/agents/approvals`, глобальная очередь, permission `agents.approve`.

Header: title, пояснение о чувствительных tools, count badge pending. Каждая карточка: человекочитаемое имя tool, агент, requested timestamp, форматированный JSON arguments в безопасном scrollable code-block, footer с secondary Deny и primary Approve.

Решение обновляет очередь; во время запроса обе кнопки конкретной карточки disabled. Ошибка остаётся над списком. Empty state сообщает, что запросов нет. Очередь автообновляется примерно каждые 5 секунд, но карточки не должны прыгать под указателем: предусмотреть мягкое удаление и устойчивый порядок.

На mobile JSON переносится/скроллится внутри карточки, две кнопки остаются минимум 44 px. Нужен визуальный акцент риска по типу действия, но не превращать все requests в одинаково красные тревоги.

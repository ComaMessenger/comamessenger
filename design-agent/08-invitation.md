# Принятие приглашения

Маршрут `/invite/:token`, самостоятельный auth-screen.

Auth-card с логотипом, заголовком «Присоединиться», lead `Coma`. Поля: отображаемое имя, handle, пароль (минимум 10 символов и видимый hint). Primary «Принять приглашение».

Состояния: валидный token; pending; server validation; истёкшее/отозванное приглашение; уже использованное; сеть. Для невалидного token не оставлять пользователя в тупике — макет должен предусмотреть сообщение и переход ко входу. После успеха пользователь автоматически входит и переходит в `/chats`.

# Важные сообщения

Маршрут `/important`. Это агрегированный список закреплённых сообщений во всех доступных чатах.

Header «Важные», mobile Back. Lead объясняет назначение. Строка: avatar чата, обрезанный текст сообщения до 120 символов, имя чата вторичной строкой, filled Star справа. Клик открывает чат и прыгает к конкретному сообщению через query `message`.

Состояния: skeleton во время параллельной загрузки pins/contexts, network error, empty «Нет важных сообщений», удалённое или недоступное сообщение пропускается. В будущем список может быть длинным, поэтому дизайн должен поддерживать pagination/virtualization без смены базовой строки.

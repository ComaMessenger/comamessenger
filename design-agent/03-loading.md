# Экран загрузки

Маршрут может быть любым; экран показывается, пока клиент выясняет bootstrap/session/branding.

Полноэкранный спокойный canvas. По центру крупный логотип Coma, под ним короткая подпись «Загрузка…». Никакой навигации, полей и ложного прогресса. Допустима мягкая ненавязчивая анимация opacity/spinner рядом с подписью, с reduced-motion вариантом.

Состояния: обычное ожидание; затянувшееся ожидание с доступным status text; при ошибке приложение переходит на Login и выводит ошибку там. Экран должен корректно выглядеть в light/dark и не мигать белым до применения темы/брендинга.

# Настройки пространства: обзор

Маршрут `/settings/workspace`; доступен owner/admin с хотя бы одним workspace capability либо участнику, которому разрешено создавать приглашения.

Header «Настройки пространства». Primary Settings nav выделяет Workspace; ниже permission-aware subnavigation: General, Members, Invitations, Policies — показываются только доступные.

Identity card: logo, organization name и роль текущего пользователя. Секция Current workspace с кратким объяснением и карточками/ссылками в доступные подразделы. Это landing page, не dashboard с множеством KPI.

Состояния: только один доступный subsection; member с правом приглашать; admin с частичными правами; access denied по прямой ссылке; длинное имя/кастомный logo. На mobile cards идут одной колонкой.

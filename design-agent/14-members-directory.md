# Участники

Маршрут `/members`, пользовательский каталог без административного редактирования.

Header «Участники», mobile Back; lead с общим количеством. Список карточек/строк: крупный avatar с presence, имя, `@handle`, опциональная должность, about и ручной статус с emoji. Справа badge типа actor (`user`/`agent`).

Нужно визуально различать presence (online/away/offline, системное) и custom status (ручной текст), не сливая их. Предусмотреть skeleton, network error, пустой каталог, длинные должности/about и будущий поиск. На mobile строки остаются touch-friendly и складывают метаданные без горизонтального скролла.

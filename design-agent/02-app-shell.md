# Общая оболочка приложения

## Desktop

Внешний canvas содержит три независимые поверхности с 8 px промежутками и радиусом 16 px: глобальная панель 220 px, список чатов 320 px только на чат-маршрутах и рабочая область. Глобальную панель можно свернуть до 58 px; остаются логотип/иконки, а подписи скрываются. Открытие workspace switcher сначала разворачивает её.

Сверху глобальной панели: логотип, обрезанное имя пространства и chevron. Popover показывает email, текущее пространство с check, ссылку в workspace settings по роли и выход. Далее плоский поиск и акцентная кнопка `+`, навигация Чаты/Треды/Важные/Участники/Агенты. Внизу закреплён профиль: avatar с online-dot, имя, `@handle` либо статус, кнопка уведомлений.

Профильное меню: крупная идентичность; текущий/пустой статус; личные настройки; DND с пресетами 30 мин/1 ч/2 ч/до завтра и custom datetime; настройки уведомлений; база знаний, report issue, updates.

## Mobile

Global sidebar скрыта. Внизу fixed tab bar из пяти равношироких icon-only действий; активное — primary color, обязательны labels для accessibility и safe-area inset. Высота контента резервирует tab bar, он не перекрывает ленту или composer.

## Глобальные слои

- In-app notification: справа сверху, avatar, title, однострочный/двухстрочный preview, close; клик открывает контекст. На mobile не перекрывает критические controls.
- Connection pill: компактный live/offline индикатор desktop; на mobile скрыт.
- Welcome в пустой рабочей области: средний логотип и короткий призыв выбрать чат.
- Любой route с обязательной сменой пароля вместо контента показывает Security screen.

## Поведение навигации

Active state зависит от URL. Списки сохраняют filter/scroll при открытии и возврате. Back на mobile явный; deep link без истории возвращает в `/chats`. Utility/settings экраны используют ту же нижнюю навигацию.

# Настройки пространства: политики создания

Маршрут `/settings/workspace/policies`, permission `workspace.policies`.

Небольшой focused screen: SettingsSection «Политики создания» с двумя SettingsToggle — разрешить публичные чаты и разрешить каналы. У каждой строки title, понятный hint о последствиях и switch справа; на mobile switch переносится под текст.

Автосохранение с Saving/Saved/Error. Следует показать зависимость, если запрет каналов влияет только на новые объекты, а не на существующие. Прямой доступ без permission — Access denied.

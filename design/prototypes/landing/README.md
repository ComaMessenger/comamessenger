# Прототип лендинга coma-chat.com

Один файл `index.html` без сборки и зависимостей. Шрифт Onest грузится из Google Fonts; без сети страница берёт системный шрифт. Маскот встроен SVG из `design/brand`.

Открыть: `open design/prototypes/landing/index.html`.

## Параметры адреса

- `?hero=1`: первый экран «Телефон сотрудника». Живой чат инструкторов: запрос с ответом одним нажатием, задача со сроком, агент «Справка» с источником.
- `?hero=2`: первый экран «Свой сервер и агенты». Тёмно-синий фон, телефон с агентом и журнал его шагов с подтверждением человеком; под кнопками полоса «Данные / Модель / Ключи».
- `?theme=light|dark`: тема; без параметра страница следует системе.

Оба параметра переключаются панелью «Прототип лендинга» вверху страницы. В рабочей вёрстке этой панели не будет.

## Блоки

Первый экран → доверие → боль «WhatsApp и Telegram» → телефон (день инструктора) → шесть рабочих функций → агенты по шагам → «ИИ делает только разрешённое» → свой сервер → открытый код → внедрение → кейс → цены → заявка → вопросы и ответы → финальный призыв.

## Тексты

Тексты прошли скиллы infostyle и humanizer-ru. Цифры на странице двух видов: факты из кода и документации (лицензии, iOS 16.4+, Android 8.0+, шифрование уведомлений) и сюжетные цифры в примерах интерфейса.

## Плейсхолдеры

Всё в `[квадратных скобках]` нужно заменить до публикации: логотипы клиентов, адрес демо, ссылки на сторы и QR-код, звёзды GitHub, срок внедрения, цифры и цитата кейса, лимит расходов в карточке агента, контакты, политика обработки персональных данных, срок ответа на заявку, планы по переносу переписки и по реестру ПО. Кнопка «Скачать презентацию» пока показывает уведомление.

## Где опубликован

С 2026-11-16 этот файл как есть отдаётся на https://coma-chat.com (сервер стейджинга
`coma-messenger-dev`). Файл лежит в `/var/www/coma-landing/index.html`, nginx —
`/etc/nginx/sites-available/coma-landing.conf` (www перенаправляется на голый домен,
сертификат Let's Encrypt `coma-chat.com`). Автодеплоя нет: после правки файл копируется
на сервер вручную (`scp … coma-messenger-dev:/var/www/coma-landing/index.html`).
Панель прототипа (варианты первого экрана, тема) скрыта, открывается по `?proto=1`.

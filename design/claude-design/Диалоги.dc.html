Диалоги, меню и overlay-состояния · 39
Общие правила: desktop dialog 500 px (поиск — 640), radius 16, border между header и body, footer с Cancel / primary. Escape, backdrop и Close предсказуемы; pending не закрывает overlay, серверная ошибка остаётся внутри. Строки меню 34–36 px на desktop, 44+ на touch. На mobile сложные диалоги fullscreen, простые подтверждения — bottom sheet.
Поиск · command palette
Autofocus поле, вкладки «Чаты и люди» и «Сообщения и треды». Люди и чаты объединены в один список. Во вкладке сообщений — фильтр по типу (все / сообщения / файлы) и по чату; запрос от 2 символов, debounce, skeleton / error / empty / load more. Footer с клавиатурными подсказками только на desktop.

Новый чат: тип (группа / канал), название, тема, участники, переключатель видимости с замком. Личный чат отдельно не создаётся — он открывается из профиля участника, каталога или поиска. Новая папка: имя, иконка из курируемой сетки с поиском, 10 семантических цветов, выбор чатов; Create disabled без имени. Инфо чата: имя и тема редактирует только управляющий, уровень уведомлений — все.
